# Instructions for AI Talk notes

## Scope

These instructions govern files inside `ai talk/`. For application changes, follow
the user's request and any instructions applicable to the affected source files.

## Maintaining this folder

- Read README.md, PROJECT.md, TASKS.md, and HANDOFF.md before updating context.
- Use clear, concise Markdown and relative links to repository files.
- Preserve the user's existing notes and unrelated work.
- Record only requested work as an active task; label suggestions as proposals.
- Never claim a check passed unless it actually ran successfully.
- Mark tasks complete only when their stated acceptance criteria are met.
- Keep secrets and personal or customer data out of all notes.
- When finishing a session, update TASKS.md and HANDOFF.md with changes,
  validation results, remaining limitations, and concrete next steps.
- Add to DECISIONS.md only when a meaningful decision is made; distinguish
  user decisions from implementation choices made by an assistant.
